# VPS デプロイ手順書

## 前提条件（初回のみ）

VPS 上で以下がセットアップ済みであること:

- Node.js (>=18)
- PostgreSQL（DB・ユーザー作成済み）
- Nginx（サイト設定済み）
- PM2（API プロセス登録済み）
- Let's Encrypt（SSL 証明書取得済み）
- プロジェクトのクローン
- `apps/api/.env` の配置（本番用に内容を修正）

---

## 毎回のデプロイ手順

### 1. ローカル: 変更を main にプッシュ

```bash
git add .
git commit -m "fix: 変更内容"
git push origin main
```

### 2. VPS に SSH 接続

```bash
ssh deploy@<VPSのIP>
```

### 3. 状態確認

```bash
cd ~/finder-backend
git status
git log -1 --oneline
pm2 status
```

### 4. 最新コードを pull

```bash
git pull --ff-only origin main
```

### 5. 依存パッケージインストール

```bash
npm ci --ignore-scripts
```

### 6. Prisma Client 生成と DB マイグレーション

```bash
cd apps/api && npx prisma migrate deploy && cd ~/finder-backend
```

### 7. API ビルド

```bash
npm run build --workspace=apps/api
```

### 8. PM2 で API 再起動

```bash
pm2 restart api
```

### 9. Web フロントエンドビルド（任意）

```bash
npm run build --workspace=apps/web
```

### 10. Web ファイルを Nginx 公開ディレクトリに同期

```bash
rsync -av --delete ~/finder-backend/apps/web/dist/ /var/www/finder-web/
```

### 11. Nginx リロード

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 12. ヘルスチェック

```bash
# API（localhost 直接）
curl -sf "http://127.0.0.1:3000/api-json" | head -c 200

# Web（外部ドメイン）
curl -s -o /dev/null -w "%{http_code}" "https://finder.miyaoo.com"
```

### 13. ログアウト

```bash
exit
```

## 自動化スクリプト

上記手順 3〜12 は `scripts/vps-deploy.sh` で一括実行できる。

```bash
cd ~/finder-backend && ./scripts/vps-deploy.sh
```
cd ~/finder-backend
git pull && ./scripts/vps-deploy.sh --skip-backup


オプション:

| オプション | 説明 |
|---|---|
| `--skip-backup` | デプロイ前のバックアップをスキップ |
| `--skip-web` | Web ビルド・デプロイをスキップ（APIのみ更新） |
| `--domain DOMAIN` | ヘルスチェック対象ドメイン |
| `--pm2-name NAME` | PM2 プロセス名 |

### DATABASE_URL が読み込まれない

Prisma は実行ディレクトリの `.env` を参照する。必ず `cd apps/api` してから prisma コマンドを実行する。
